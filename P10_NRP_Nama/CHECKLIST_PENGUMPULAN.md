# Checklist Pengumpulan Praktikum 10

Ganti identitas dan nama folder sebelum mengumpulkan.

- [ ] Folder diberi nama `P10_NRP_Nama`
- [ ] Nama dan NRP sudah diisi pada `README.md`
- [ ] File utama `.blend` tersedia
- [ ] File berasal dari hasil P9 atau setara
- [ ] Scale diperiksa dan diterapkan bila diperlukan
- [ ] Normal geometry diperiksa
- [ ] Seam manual ditandai dan alasan seam dapat dijelaskan
- [ ] Manual UV Unwrap dilakukan
- [ ] UV Island dapat dibaca di UV Editor
- [ ] Checker test dilakukan
- [ ] Distortion dan texel density diperiksa
- [ ] UV Islands dipack dengan margin yang layak
- [ ] Tidak ada accidental overlap
- [ ] Principled BSDF digunakan
- [ ] Base Color memakai sRGB
- [ ] Roughness memakai Non-Color
- [ ] Metallic memakai Non-Color
- [ ] Normal Map memakai Non-Color dan melewati Normal Map node
- [ ] Emission ditambahkan pada area yang relevan
- [ ] Node graph rapi dan dapat dijelaskan
- [ ] Minimal dua challenge dikerjakan
- [ ] Semua texture masih tersedia pada folder `textures/`
- [ ] Minimal 10 screenshot bukti proses tersedia
- [ ] Kendala, solusi, dan refleksi sudah ditulis pada `README.md`
- [ ] File dibuka ulang dan material tetap berfungsi
